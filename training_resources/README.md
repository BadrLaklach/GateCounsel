# External Training References

This directory keeps third-party security references separate from the project-curated examples in `training_data/`.

| Resource | Folder | Role |
|---|---|---|
| PayloadsAllTheThings | [`payloads_all_the_things/`](payloads_all_the_things/README.md) | Payload and technique reference; local snapshot is incomplete because Windows Security blocked files during import. |
| HackTricks | [`hacktricks/`](hacktricks/README.md) | Web-security and methodology reference; upstream source is linked but not copied into this workspace. |

These folders are reference material only. No application code, imports, configuration, planner behavior, or runtime data loading has been connected to them. The existing `training_data/` files were left in place.

Source status and licensing are recorded separately for each resource. Verify the upstream source before treating any local snapshot as complete.
